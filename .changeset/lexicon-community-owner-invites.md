"Community owners may create invite codes" setting: `net.openfederation.invite.create` (revision 4) returns the `CommunityOwnerInvitesOff` error when the server lets only admins create community invite codes; `net.openfederation.admin.getServerSettings` and `updateServerSettings` (revision 3) list the setting `communityOwnerInvites`.
